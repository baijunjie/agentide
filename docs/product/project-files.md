# 项目登记与文件浏览

项目文件只由 Mac 上的 Agent Host 访问。用户先在 Mac 明确登记一个目录，iPhone 才能通过已配对设备之间的 Relay 消息取得该项目的公开元数据、浏览或搜索文件树，并只读查看文本与图片。Relay 只路由请求与响应，不读取或持久化项目根路径、文件树、搜索记录或文件内容。

## 项目登记

- Mac 的 Projects 页面允许选择一个本机目录进行登记。Agent Host 把目录解析为规范路径；同一规范路径不能重复登记，非目录不能登记。
- 新项目默认以目录名作为显示名。显示名可以修改；删除操作只删除 AgentIDE 的登记记录，不修改本机项目目录或其中的文件。
- 项目登记持久化在 Mac 本地，包含稳定项目 ID、显示名、规范根路径、创建时间和已启用 Agent。Claude 的执行能力随 Agent Host 依赖提供，因此所有新登记项目都会启用 Claude，加载既有登记时也会补齐该能力；Codex 仅在当前 `PATH` 中存在可执行的 `codex` 时启用。
- 根路径只供 Mac 本地授权与文件访问使用。iPhone 取得的项目元数据只有项目 ID、显示名、创建时间、可用 Agent 和在线状态，不包含本机绝对路径。

## 在线项目与请求路径

Mac 应用是项目业务消息的唯一 Relay 连接持有者。iPhone 在已配对 Mac 上线时发送 `project.list`，Mac 从本地 Agent Host 取得登记项目，并以 `project.list.response` 返回公开元数据。项目是否在线取决于 Mac 的 Relay 连接状态。

iPhone 进入项目时以空相对路径请求根目录；展开尚未加载的目录时发送 `project.listFiles`，Mac 通过本地 Agent Host 列出目录后返回 `project.listFiles.response`。目录内容按需加载，不预先传输整棵文件树。

文件搜索使用 `project.searchFiles`，请求包含本次查询唯一的 `searchId`、查询文本和结果上限；响应回显 `searchId` 与查询文本，并返回 `FileEntry` 结果和表示结果不完整的 `hasMore`。取消使用 `project.cancelSearch` 引用同一个 `searchId`。搜索结果不提供分页游标，`hasMore` 为真时客户端提示用户缩小查询。

打开文本或图片时，iPhone 发送 `project.readFile`，以 `utf8` 或 `base64` 指定响应内容的编码。图片 Viewer 还会发送 `project.listImages`，取得当前图片与同目录图片列表。Mac 把这些请求转换为 Agent Host 的本地文件接口，再把结果封装为对应的 `.response` Envelope；Relay 不解释内容。

iPhone 以响应的 `replyTo` 匹配原请求，不接受无法匹配请求类型、项目、路径、`searchId` 或查询文本的结果。离线、连接中断、发送失败、无效响应、15 秒超时和 Mac 返回的文件错误都会结束对应请求，并在原目录行、搜索结果或 Viewer 中提供 Retry。普通项目请求以 `project_request_failed` 返回失败，搜索请求使用 `project_search_failed`；本机文件系统错误不会被当作成功结果。

## 文件浏览交互

- iPhone 从项目进入 Session List；用户可以从 Session List 或具体的 Agent Session 打开该项目的文件浏览器，并在文件浏览与会话工作之间往返。Session List、文件浏览器和具体会话也提供当前工作树的 Changes 入口；变更审查行为见 [Git 变更与统一 Diff 审查](git-changes.md)。
- 从 Agent Session 打开文件浏览器时，会话、文件浏览器和文本 Viewer 组成连续的三层工作区。会话层可通过右上角文件夹按钮或从屏幕右侧起手向右拖动进入文件浏览器；文件浏览层可从屏幕右侧起手向左拖动返回会话。进入下一层后，上一层退到左侧并停止接收内部交互，也不再出现在辅助功能树中；点按左侧保留区域可逐级返回。未达到切换条件的拖动会弹性回到当前层。
- 文本 Viewer 为避免与源码的水平滚动冲突，不接管页面内的横向拖动；用户通过右上角独立把手向左拖动返回文件浏览器。图片仍使用独立的全屏分页 Viewer，不进入三层工作区的文本层。
- 文件树以内联缩进呈现层级；目录可以展开和收起，首次展开时才加载其直接子项。
- 每项同时显示名称、项目内相对路径和类型图标。目录、Markdown、其他文本、图片和不可打开的普通文件使用不同图标；文本与图片可以打开，不支持查看的普通文件只用于识别。
- 长按任意文件或目录可以复制名称或项目内相对路径。
- iPhone 保存每个最近项目的已展开目录和滚动位置。应用重启后会按父目录到子目录的顺序按需重新加载已展开分支，只在目标再次可见时恢复滚动位置；已不存在或不再可访问的分支会从恢复状态中移除。
- Agent Host 默认隐藏名为 `.git`、`node_modules`、`DerivedData`、`.build` 或 `Pods` 的路径段；这些路径既不会出现在目录列表中，也不能通过直接构造相对路径读取。该忽略集合当前不能由用户修改。

## 项目文件搜索

- File Browser 顶部的搜索框先去除首尾 Unicode `White_Space`；结果为 2 至 256 个 Unicode 标量时，在输入停止 300 毫秒后发起查询。少于两个标量时提示继续输入，超过上限时提示查询过长且不发送请求。查询文本保留在离线、超时和服务端失败状态中，用户可以直接重试。
- 搜索只匹配名称和项目内相对路径，不读取文件内容。查询与候选文本依次执行 NFKC、Unicode CaseFolding 17.0.0 默认完整折叠（C 与 F 映射，不含 Turkic T 映射）和再次 NFKC；大小写折叠不依赖设备区域设置或系统自带的大小写映射表。名称以规范化查询开头的结果优先，其余匹配按规范化后的相对路径稳定排序。
- 搜索返回文件和目录，并沿用文件树的名称、相对路径、类型和可查看能力。文本、Markdown 与图片从结果直接进入现有 Viewer；目录结果退出搜索状态并在文件树中逐层加载、展开和定位对应分支。定位期间目录已不存在或不可访问时，界面显示可恢复错误并清除无效恢复状态。
- 每次搜索同时受最多 100 条结果、50,000 个已遍历条目、5 秒执行时间和 700 KiB 结果数据限制。任一限制导致结果不完整时，响应设置 `hasMore`，客户端提示缩小查询。搜索不保证目录并发变化期间的快照一致性；遍历中的子目录已消失或变为符号链接时，Agent Host 保留已经取得的结果、跳过该子树并设置 `hasMore`，重新搜索可取得当前状态。
- 新查询会先取消同一项目的旧查询；离开 File Browser 或请求超时也会发送取消。Mac 将不同 iPhone 的 `searchId` 隔离后转交 Agent Host，Agent Host 终止正在进行的遍历；取消即使先于对应搜索到达，也会在短时乱序窗口内阻止该 `searchId` 随后启动遍历。已取消或已被替换的响应不能覆盖当前结果。
- Agent Host 最多同时执行四个不同 `searchId` 的文件搜索，不为超额请求排队；超出并发上限时本地 IPC 返回 HTTP 503 和稳定错误码 `search_busy`，Mac 将其作为 `project_search_failed` 返回 iPhone，查询文本仍保留并可重试。
- iPhone 按项目保存最近 10 条成功搜索，重复文本忽略大小写后合并到最新位置。历史只写入 iPhone 本地，可单项移除或全部清除，不会发送给 Mac 或 Relay。

## 文本与图片查看

- 文本 Viewer 只读。Markdown 默认显示渲染结果；其他文本以等宽字体显示行号，并支持水平与垂直滚动。Viewer 显示文件名和项目内相对路径，两者均可复制。
- 文本、Markdown 和图片 Viewer 都可把当前文件复制为 `@<项目内相对路径>` 形式的 Agent 引用。从具体 Agent Session 进入文件浏览时，还可以把该引用追加到当前会话草稿并返回会话，不会立即发送；从 Session List 直接浏览时只提供复制。会话草稿的保留与发送规则见 [Agent 会话执行与事件投递](agent-sessions.md#iphone-会话与交互界面)。
- 图片使用全屏分页 Viewer，并可在同目录图片之间左右切换。当前图片与相邻图片会预取；解码后的最长边不超过 2048 像素，并保存在有界内存缓存中。
- 图片支持双指缩放、双击缩放和放大后的拖动；图片处于放大状态时，左右分页暂停，避免拖动图片时误切页。
- 关闭文本或图片 Viewer 后，文件树此前的展开项和滚动位置仍然保留；从最近会话恢复工作区时，也会回到原有的文件浏览或文本查看层。

## 项目根目录边界

所有文件操作都以项目 ID 和项目内相对路径定位目标；调用方不能提交任意 Mac 路径。Agent Host 拒绝绝对路径、反斜杠路径、包含 `..` 的路径和默认忽略的路径段。

实际文件访问从文件系统根目录开始，先逐段打开已登记的项目根路径，再逐段打开项目内相对路径，并且任何一段都不跟随符号链接；目录列表只返回普通目录和普通文件。因此符号链接不会出现在文件树中，也不能用于读取文件，即使链接目标仍在项目根目录内。路径约束与实际打开在同一次逐段访问中完成，并发地把项目根路径的祖先目录或项目内目录替换为符号链接，也不能绕过项目边界。

Agent Host 的目录列举、文件搜索、文本读取、二进制读取和同目录图片列举使用同一项目根目录边界。搜索与文件树使用相同的默认忽略集合，并且不返回符号链接。原生 helper 对单次读取的原始字节设置 700 KiB 上限，即使文件在打开后继续增长也不能越过该上限；Mac 在发送前还会检查最终 Envelope 不超过 1 MiB。读取上限被触发时，iPhone 收到 `project_request_failed`，不会取得截断内容。

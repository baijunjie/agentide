# 项目登记与文件浏览

项目文件只由 Mac 上的 Agent Host 访问。用户先在 Mac 明确登记一个目录，iPhone 才能通过已配对设备之间的 Relay 消息取得该项目的公开元数据、浏览文件树并只读查看文本与图片。Relay 只路由请求与响应，不读取或持久化项目根路径、文件树或文件内容。

## 项目登记

- Mac 的 Projects 页面允许选择一个本机目录进行登记。Agent Host 把目录解析为规范路径；同一规范路径不能重复登记，非目录不能登记。
- 新项目默认以目录名作为显示名。显示名可以修改；删除操作只删除 AgentIDE 的登记记录，不修改本机项目目录或其中的文件。
- 项目登记持久化在 Mac 本地，包含稳定项目 ID、显示名、规范根路径、创建时间和已启用 Agent。Claude 的执行能力随 Agent Host 依赖提供，因此所有新登记项目都会启用 Claude，加载既有登记时也会补齐该能力；Codex 仅在当前 `PATH` 中存在可执行的 `codex` 时启用。
- 根路径只供 Mac 本地授权与文件访问使用。iPhone 取得的项目元数据只有项目 ID、显示名、创建时间、可用 Agent 和在线状态，不包含本机绝对路径。

## 在线项目与请求路径

Mac 应用是项目业务消息的唯一 Relay 连接持有者。iPhone 在已配对 Mac 上线时发送 `project.list`，Mac 从本地 Agent Host 取得登记项目，并以 `project.list.response` 返回公开元数据。项目是否在线取决于 Mac 的 Relay 连接状态。

iPhone 进入项目时以空相对路径请求根目录；展开尚未加载的目录时发送 `project.listFiles`，Mac 通过本地 Agent Host 列出目录后返回 `project.listFiles.response`。目录内容按需加载，不预先传输整棵文件树。

打开文本或图片时，iPhone 发送 `project.readFile`，以 `utf8` 或 `base64` 指定响应内容的编码。图片 Viewer 还会发送 `project.listImages`，取得当前图片与同目录图片列表。Mac 把这些请求转换为 Agent Host 的本地文件接口，再把结果封装为对应的 `.response` Envelope；Relay 不解释内容。

iPhone 以响应的 `replyTo` 匹配原请求，不接受无法匹配请求类型、项目或路径的结果。离线、连接中断、发送失败、无效响应、15 秒超时和 Mac 返回的文件错误都会结束对应请求，并在原目录行或 Viewer 中提供 Retry。Mac 统一以 `project_request_failed` 返回项目请求失败，不把本机文件系统错误当作成功结果。

## 文件浏览交互

- iPhone 从项目进入 Session List；用户可以从 Session List 或具体的 Agent Session 打开该项目的文件浏览器，并在文件浏览与会话工作之间往返。
- 文件树以内联缩进呈现层级；目录可以展开和收起，首次展开时才加载其直接子项。
- 每项同时显示名称、项目内相对路径和类型图标。目录、Markdown、其他文本、图片和不可打开的普通文件使用不同图标；文本与图片可以打开，不支持查看的普通文件只用于识别。
- 长按任意文件或目录可以复制名称或项目内相对路径。
- Agent Host 默认隐藏名为 `.git`、`node_modules`、`DerivedData`、`.build` 或 `Pods` 的路径段；这些路径既不会出现在目录列表中，也不能通过直接构造相对路径读取。该忽略集合当前不能由用户修改。

## 文本与图片查看

- 文本 Viewer 只读。Markdown 默认显示渲染结果；其他文本以等宽字体显示行号，并支持水平与垂直滚动。Viewer 显示文件名和项目内相对路径，两者均可复制。
- 图片使用全屏分页 Viewer，并可在同目录图片之间左右切换。当前图片与相邻图片会预取；解码后的最长边不超过 2048 像素，并保存在有界内存缓存中。
- 图片支持双指缩放、双击缩放和放大后的拖动；图片处于放大状态时，左右分页暂停，避免拖动图片时误切页。
- 关闭文本或图片 Viewer 后，文件树此前的展开项和滚动位置仍然保留。

## 项目根目录边界

所有文件操作都以项目 ID 和项目内相对路径定位目标；调用方不能提交任意 Mac 路径。Agent Host 拒绝绝对路径、反斜杠路径、包含 `..` 的路径和默认忽略的路径段。

实际文件访问从文件系统根目录开始，先逐段打开已登记的项目根路径，再逐段打开项目内相对路径，并且任何一段都不跟随符号链接；目录列表只返回普通目录和普通文件。因此符号链接不会出现在文件树中，也不能用于读取文件，即使链接目标仍在项目根目录内。路径约束与实际打开在同一次逐段访问中完成，并发地把项目根路径的祖先目录或项目内目录替换为符号链接，也不能绕过项目边界。

Agent Host 的目录列举、文本读取、二进制读取和同目录图片列举使用同一项目根目录边界。原生 helper 对单次读取的原始字节设置 700 KiB 上限，即使文件在打开后继续增长也不能越过该上限；Mac 在发送前还会检查最终 Envelope 不超过 1 MiB。任一上限被触发时，iPhone 收到 `project_request_failed`，不会取得截断内容。

# 移动端界面体验改善

## 范围

对照 iPhone 上已经实现的功能做一轮界面检查：配对与项目列表、会话列表与新建、Activity Feed、审批与提问、结构化报告、文件浏览与搜索、文本和图片查看、Changes 与 Diff。不新增产品能力，不改协议，也不把代码编辑、Git 写操作或 Push 拉进来。

检查在 iPhone 17 模拟器的 Debug 构建上进行，用 `-mobileScenario` 走正式的 `MobileConnection` 状态流。动态类型用 Accessibility XL，深色模式单独看过会话和 Diff。场景数据里没有工具调用，命令事件也没有输出字段，会话里没有多段 Markdown，图片是 1×1 像素。这几处只记录代码里能确定的呈现，没有对应截图。和产品文档一致的呈现不记成缺陷；想改呈现的单独写成提案。

## 已经成立的部分

- 离线空态、超时和请求失败都有明确文案，失败时不会再叠一层 `Mac Online` 或 `No Projects`。
- 等待用户时，顶部有 `Answer question` / `Review approval`，输入区说明为什么不能发送。
- 报告卡片默认折叠，测试、计划和诊断的摘要在折叠态就能读。
- Changes 按 Staged / Unstaged 分组，二进制和超限 diff 有单独状态，超限会说明再试一次发出的仍是同一个请求。
- 从会话进入文件或 Diff 时，左侧留出上一层，导航栏 Back 只退一层。
- Markdown 文件能分开标题和段落。搜索历史、清除和 `hasMore` 提示都在。
- 文件树只显示名称，层级靠缩进。搜索结果在相对路径与名称不同时，于名称下再显示相对路径。
- 非 Markdown 文本里，普通句子按行号右侧的宽度换行。没有空白或超过 160 个标量的行单独横滑，行号留在横向滚动外面。
- 搜索去掉首尾空白后不足 2 个或超过 256 个标量时，最近搜索和文件树留着，长度提示在搜索框下一行，不发请求。

## 不在本轮

- 会话删除、归档、时间戳和推送。
- 运行中排队发送，以及运行中继续编辑下一句草稿。只有 `idle` 能发送；不能发送时输入区说明原因。这是 `docs/product/agent-sessions.md`「iPhone 会话与交互界面」的约定。
- 把状态、轮次完成、会话完成从活动块改成时间线。详情超过 8 条仍在卡片内滚动，前 50 条和截断说明不动。同一节已经写明。
- 给会话列表工具栏加 `Files` / `Changes` / `New`。可见文字会挤占完整项目名；入口已经有辅助功能名。
- 为横屏重做三层空间。方向策略定下来之前，不把强制横屏的截图当成已确认的用户路径。
- 图片查看器的内容。场景图只有 1×1 像素，顶栏的关闭、文件名和操作菜单是可见的，缩放和翻页没有可看的画面。

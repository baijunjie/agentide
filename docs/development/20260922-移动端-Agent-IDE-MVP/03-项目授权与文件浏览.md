# 03 项目授权与文件浏览

> 目标: 让 Mac 登记可访问项目，并让 iPhone 在不越出项目根目录的前提下浏览完整文件树。
> 完成判据: 用户可在 Mac 添加项目，iPhone 可看到在线项目、展开和折叠目录，并复制文件或文件夹名称与相对路径；路径遍历和符号链接逃逸均被拒绝。

## 技术设计

- [ ] 复用里程碑 01 的 `Project` 契约，Mac 支持添加目录、删除登记、重命名显示名与检测 Claude Code/Codex 可用性。
- [ ] 文件服务提供 list directory、read text file、read binary file 和 list sibling images 的内部能力，本里程碑对外开放 `project.listFiles`。
- [ ] 文件树响应复用里程碑 01 的 `FileEntry` 契约。
- [ ] 传入路径按项目根目录与标准化相对路径组合，解析后再验证最终路径仍在根目录内。
- [ ] 禁止 `../` 路径遍历、绝对路径逃逸和符号链接逃逸。
- [ ] MVP 默认忽略 `.git`、`node_modules`、`DerivedData`、`.build` 和 `Pods`，本阶段不开放用户自定义规则。

## 实现方案

- [ ] Mac 项目列表展示登记项目与在线状态，提供 Add Project 入口，不修改项目本身。
- [ ] iOS 从已配对 Mac 获取 project metadata，进入项目后按需请求子目录。
- [ ] File Browser 使用缩进、展开/收起动画和连续路径视觉表达层级，文本、Markdown、图片与不可打开文件都可出现在列表中。
- [ ] 文件和文件夹的长按菜单提供 Copy Name 与 Copy Relative Path，便于用户回到 Agent 输入框粘贴。

## 开发要点

- 文件读取权限以 Mac 显式登记的 Project 为唯一边界，iOS 不能传入任意 Mac 路径。
- Server 只路由文件请求与响应，不保存文件树或文件内容。

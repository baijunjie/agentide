# 04 文本与图片查看

> 目标: 在已安全浏览项目文件树的基础上，完成只读文本、Markdown 和图片查看闭环。
> 完成判据: 用户可从 File Browser 进入 Text File Viewer 查看源码或渲染后的 Markdown，可全屏查看图片并左右切换同目录图片，关闭后恢复原文件树状态。

## 技术设计

- [ ] 对外开放 `project.readFile` 和 `project.listImages`，仍使用上一里程碑的项目根目录安全校验。
- [ ] 文本 Viewer 只读，普通源码使用等宽字体、行号和横向滚动；Markdown 默认显示渲染结果。
- [ ] Viewer 顶部展示文件名与相对路径，并支持 Copy File Name 和 Copy Relative Path。
- [ ] 图片请求返回 current 与同目录 siblings，图片 Viewer 使用分页模式。
- [ ] 图片 Viewer 支持 pinch zoom、double tap zoom、drag 和 swipe left/right，不进入文本文件的 Level 2 层级。
- [ ] 导航状态能保留 File Browser 的展开项、当前路径和滚动位置，以便关闭 Viewer 后恢复。

## 实现方案

- [ ] 文本文件的点击建立文件选中状态，并以第二级右滑的视觉语义进入 Viewer；可由点击自动触发该推进动画。
- [ ] 进入文本 Viewer 时 Session 主屏完全离场，File Browser 退到左侧，Viewer 占据主要空间。
- [ ] 点击图片时直接打开全屏 Image Viewer，关闭后回到原 File Browser 上下文。
- [ ] 简单 syntax color 只在开发时间允许时按扩展名提供，不作为本里程碑验收前提。

## 开发要点

- 不实现 Source/Preview 切换、Send to Agent、当前文件引用或选中行引用。

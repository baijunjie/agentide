# 08 三层空间手势打磨

> 目标: 将 Session → File Browser → Text File Viewer 打磨为稳定、连续且符合 iPhone 操作习惯的三层空间导航系统。
> 完成判据: 在真机上可通过右滑进入、左滑或点击退出区域返回，各层的缩放、雾化、位移、层叠与滚动不冲突，横竖屏和安全区域下均能正常返回。

## 技术设计

- [ ] 建立独立 Workspace Navigation State，至少表达 session、browser、file(FileReference) 三层，并容纳全屏 Image Viewer 状态。
- [ ] 主容器统一管理 offset、scale、blur、opacity、zIndex 和 gesture progress，不用系统 `NavigationStack` 模拟整个空间层级。
- [ ] Level 0 激活时 Session 保持正常比例；进入 Level 1 后 Session 缩到左侧约 1/4，缩放至约 0.92–0.96，并应用适度雾化与透明度。
- [ ] File Browser 激活时占据右侧约 3/4；进入 Level 2 后，File Browser 使用类似退场参数，Session 完全离场。
- [ ] 退到左侧的层级禁止内部交互，但可作为点击返回区域，保留当前 Session 或 Files 上下文。
- [ ] 具体视觉数值在真机调优，不写入协议层。

## 实现方案

- [ ] 调整 gesture threshold 与 interactive animation，使手势进度可连续驱动位移、缩放、雾化、阴影和透明度。
- [ ] 处理 File Browser 纵向滚动、文本 Viewer 横向滚动、系统边缘手势与层级手势之间的冲突。
- [ ] 处理 safe area、方向变化、不同屏幕尺寸与 z-index，避免激活层被遮挡或退场层误接收交互。
- [ ] 验证文本 Viewer 与全屏 Image Viewer 使用不同进入方式，但都能回到原 File Browser 位置。
- [ ] 使用真机完整检查 Session → Files → Text File、Session → Files → Image 与逐级返回。

## 可复用能力

- 里程碑 03–04 的 File Browser、Text File Viewer、Image Viewer 及它们的状态保留机制。
- 里程碑 07 的 Agent Session 容器与会话上下文。

# 移动端界面体验复查

## 问题

上一轮可读性与返回改完之后，用现在的 iPhone 客户端把已实现的画面又走了一遍。还在的问题集中在四块：空间层里变更和 diff 读不全、短源码浮在中部且长行被裁切、文件菜单的 `Send to Agent` 实际只把引用写入当前会话草稿并返回（不会发送）、会话动态顶部空出一截且失败报告用了成功图标、项目首页和配对页把同一件事说了两遍。扫码页在没有相机画面时是一张白纸。

不新增产品能力：不加入源码编辑、Git 写操作、推送、新平台或新协议。界面文案保持英文。

## 方案

四块互不依赖，做完一块就可以单独验证、单独合并。空间层变窄时，变更行仍要读完现在这三条路径和完整状态，全宽变更列表维持现在的样子。源码短文件顶对齐，横向滚动时行号留在左侧。`Send to Agent` 要能看出只把引用写入当前会话草稿并返回，不会发送。会话动态去掉导航栏下的空白，失败报告不再用勾。首页各只说一次连接状态和解除配对。配对页的导航标题和大号标题只留一处应用名，说明句子里的应用名保留；相机没有预览时说明原因并可以关闭。

## 检查方法

2026-09-29，iPhone 17 模拟器（iOS 26.5），Debug 构建，启动参数 `-mobileScenario`。进程内 Mac 替身，不经 Relay，不持久化身份。截图是模拟器帧，逻辑分辨率 402×874，状态栏为 9:41。

走过的场景：`comprehensive`、`offline`、`request-failure`、`timeout`、`not-git`、`clean`、`too-large`、`search-empty`、`search-limited`、`search-missing-directory`。配对页和扫码页在解除配对之后看过。

深色外观留下两张：[项目首页](screenshots/12-projects-dark.png) 和 [会话动态](screenshots/07-session-dark.png)。这两张上的问题和浅色相同。深色下的变更列表和 diff 没有截到。Dynamic Type XXXL 和横屏没有跑完。这三项不写成待修项。图片夹具是 1×1 PNG，图片查看器的关闭、标题和路径是齐的，不把黑色图片记成缺陷。

## 这次核对过、不再列入

这些画面按当前产品行为是齐的，后续改动不要把它们改回去：

- 会话列表标题能放下 `Scenario Workspace`；状态徽章是 `Waiting for you`。
- 新建会话在任务为空时不能创建，输入框有提示。
- 有未回答的问题或未决审批时，输入区说明要先处理；提问和审批卡片本身可读。
- 长报告在卡片内部滚动。Markdown 标题和段落是分开的，并且顶对齐。
- 从会话列表进入的全宽变更列表能读完路径和状态。短 diff 已经顶对齐。
- 搜索：输入太短是 `Keep Typing`；有结果；结果过多有「还有更多」的页脚；目录已不在时有横幅；无结果是空态。
- 失败、超时、超限 diff、非 Git、干净工作区、二进制 diff 各自有说明。失败和超时可以重试。非 Git 与干净工作区不是同一个标题。
- 解除配对前有确认，说明只撤销这台 iPhone。

# 08 三层空间手势打磨

> 目标: 将 Session → File Browser → Text File Viewer 打磨为稳定、连续且符合 iPhone 操作习惯的三层空间导航系统。
> 完成判据: 在真机上可通过右滑进入、左滑或点击退出区域返回，各层的缩放、雾化、位移、层叠与滚动不冲突，横竖屏和安全区域下均能正常返回。

## 落地状态

- Session、File Browser 和 Text File Viewer 已接入独立 Workspace Navigation State 与同一空间容器；交互进度统一驱动位移、缩放、雾化、透明度、阴影和层叠，未完成的拖拽会弹性回位。宽屏时左侧退场区域设有最大宽度，横竖屏共用同一几何口径。
- Session 与 File Browser 使用避开系统返回边缘的定向空间手势。Text File Viewer 为避免与源码横向滚动竞争，最终改用右上角独立左拖把手；左侧退场区域仍可点击逐层返回。退场层同时关闭触摸命中和辅助功能访问。
- File Browser 在进入文本或全屏图片后保留展开项与滚动位置；文本层随空间容器进退场，图片继续使用全屏分页 Viewer，并返回原文件树上下文。
- 已验证 `pnpm check`、`pnpm test`、`pnpm check:swift`、iOS Simulator 通用目标构建，并在 iPhone 17 Pro Simulator 安装启动。当前模拟器没有已配对 Mac，未执行 Session → Files → Text/Image 的完整数据路径；横竖屏、手势阈值与安全区域仍须在已配对的真机上完成最后一项验收。

## 技术设计

- [x] 建立独立 Workspace Navigation State，至少表达 session、browser、file(FileReference) 三层，并容纳全屏 Image Viewer 状态。
- [x] 主容器统一管理 offset、scale、blur、opacity、zIndex 和 gesture progress，不用系统 `NavigationStack` 模拟整个空间层级。
- [x] Level 0 激活时 Session 保持正常比例；进入 Level 1 后 Session 缩到左侧约 1/4，缩放至约 0.92–0.96，并应用适度雾化与透明度。
- [x] File Browser 激活时占据右侧约 3/4；进入 Level 2 后，File Browser 使用类似退场参数，Session 完全离场。
- [x] 退到左侧的层级禁止内部交互，但可作为点击返回区域，保留当前 Session 或 Files 上下文。
- [x] 具体视觉数值在真机调优，不写入协议层。

## 实现方案

- [x] 调整 gesture threshold 与 interactive animation，使手势进度可连续驱动位移、缩放、雾化、阴影和透明度。
- [x] 处理 File Browser 纵向滚动、文本 Viewer 横向滚动、系统边缘手势与层级手势之间的冲突。
- [x] 处理 safe area、方向变化、不同屏幕尺寸与 z-index，避免激活层被遮挡或退场层误接收交互。
- [x] 验证文本 Viewer 与全屏 Image Viewer 使用不同进入方式，但都能回到原 File Browser 位置。
- [ ] 使用真机完整检查 Session → Files → Text File、Session → Files → Image 与逐级返回。
